# Audio attribution

## Sinhala pronunciation

The bundled Sinhala pronunciation clips were generated from the curriculum's Sinhala Unicode text with **SinhalaVITS**, a Sinhala-specific text-to-speech project from Dialog Axiata PLC and the Dialog–University of Moratuwa Mobile Communications Research Laboratory.

- Project: [dialoglk/SinhalaVITS](https://huggingface.co/spaces/dialoglk/SinhalaVITS)
- Model family: VITS, trained on native Sinhala speaker recordings
- Voice used: Female Voice 2
- Model licence: Mozilla Public License 2.0
- App encoding: mono MP3 for compact offline playback

The model itself is not bundled with LingoLanka. Only the generated pronunciation clips are shipped. Language learners should still report any word that sounds contextually or regionally incorrect so it can be reviewed against the source text and replaced without changing learner progress.

## English pronunciation

English clips are bundled for reliable playback. Text outside the packaged curriculum can use a compatible browser or operating-system voice.
