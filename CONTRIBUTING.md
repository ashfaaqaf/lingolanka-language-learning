# Contributing to LingoLanka

Thank you for improving free bilingual learning.

1. Open an issue describing the correction or feature.
2. Create a focused branch and keep content separate from UI.
3. Preserve valid Sinhala Unicode and the documented transliteration convention.
4. Never add paid APIs, advertising, tracking, accounts, fake analysis or unfinished controls.
5. Run `npm ci`, `npm run lint`, `npm run typecheck`, `npm run test` and `npm run build`.

For language corrections, include context, formality, region where relevant, and a reliable source or fluent-speaker review. Add uncertain entries to `CONTENT_REVIEW.md`.
